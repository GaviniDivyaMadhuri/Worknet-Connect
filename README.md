WorkNet Connect 📍💼

WorkNet Connect is a proximity-based service marketplace built with Flutter and Node.js. It allows users to find available service providers (plumbers, electricians, etc.) based on their real-time location and availability status.

🚀 Key Features

Geospatial Search: Find workers within a specific radius (5km - 20km) using MongoDB's 2dsphere indexing.

Real-time Availability: Workers can toggle their "Available" status to appear in or disappear from search results instantly.

Work Portfolios: Workers can upload text and image "posts" to showcase their completed projects.

Automated Location Fetching: Integrates the geolocator package to automatically detect client coordinates for seamless searching.

Secure Authentication: Password protection using bcrypt hashing.
